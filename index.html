เซ็นลายเซ็นดิจิทัลที่นี่

ตั้งค่าการเชื่อมต่อ Google API

เชื่อมต่อแผนการสอนหน้าเดียวเข้ากับ Google Sheets และ Google Drive เพื่อเก็บประวัติการบันทึกหลังสอนและอัปโหลดไฟล์ PDF

ได้จากขั้นตอนการ Deploy Web App ในหน้าต่าง Apps Script ของ Google Sheets
ระบุ ID ของโฟลเดอร์ใน Drive หากต้องการบังคับบันทึกลงในโฟลเดอร์เฉพาะ

วิธีติดตั้งระบบหลังบ้าน:

  1. คัดลอกโค้ดจากไฟล์ google-apps-script.js ในโปรเจกต์นี้
  2. ไปที่ Google Sheet ของคุณ เลือก ส่วนขยาย > แอปสคริปต์ (Apps Script)
  3. วางโค้ดลงไป กดบันทึก แล้วกดปุ่ม ทำให้ใช้งานได้ใหม่ (New Deployment) เลือกประเภท เว็บแอป (Web App)
  4. ตั้งสิทธิ์การเข้าถึงให้เป็น ทุกคน (Anyone) จากนั้นกด Deploy และนำลิงก์ที่ได้มาวางในช่องด้านบน
